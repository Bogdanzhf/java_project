# Сервис сбора курсов валют

Итоговая практическая работа по дисциплине «Теория и практика многопоточности». Вариант 4 — многопоточный сервис получения и хранения курсов валют Центрального банка Российской Федерации. Жадан Богдан

## Назначение

Приложение получает официальный XML-документ ЦБ РФ, извлекает код и наименование валюты, курс к рублю, номинал и изменение курса относительно предыдущей даты. Результаты хранятся во встроенной файловой базе H2 (`data/currencydb.mv.db`) и доступны через HTTP API.

После старта в H2 добавляются отсутствующие курсы на текущую дату для пяти демонстрационных валют: USD, EUR, CNY, GBP и JPY. Поэтому получение результатов доступно сразу, в том числе когда внешний сайт временно недоступен; собранные данные сохраняются между перезапусками.

## Требования для запуска

* Java Development Kit 17 или новее;
* подключение к интернету необходимо только для первого запуска Maven Wrapper и для обновления данных с ЦБ РФ.

Устанавливать Maven отдельно не требуется: в архив включён Maven Wrapper.

## Запуск

### Сборка и запуск

Откройте PowerShell в корне проекта и выполните:

```powershell
.\mvnw.cmd clean verify
.\run.bat
```

На первом запуске Wrapper автоматически загрузит Maven 3.9.9. Команда `clean verify` выполнит тесты и соберёт исполняемый JAR со всеми зависимостями приложения. `run.bat` запускает эту сборку из `target/`; если её нет — использует готовый JAR из `release/`. После строки `Started CurrencyParserApplication` сервис доступен по адресу `http://localhost:8080`.

Для сборки и запуска требуется JDK 17 или новее. Если в `PATH` выбрана другая версия Java, укажите JDK 17 в переменной `JAVA_HOME`; `run.bat` использует её напрямую.

### Готовое приложение

В архив включён самодостаточный файл `release/currency-rate-parser-1.0.0.jar`. Его можно запустить командой:

```powershell
.\run.bat
```

Для остановки приложения нажмите `Ctrl+C` в том же окне терминала.

Для обновления данных с ЦБ РФ требуется доступ к `www.cbr.ru` и доверенная TLS-цепочка сертификатов в JDK. Если среда использует корпоративный HTTPS-прокси, его корневой сертификат должен быть корректно настроен в доверенном хранилище Java; не отключайте проверку TLS.

## Проверка API

### Получить все результаты

```http
GET http://localhost:8080/answer
```

Параметры: `date` — дата в формате `YYYY-MM-DD`; `currencies` — коды через запятую; `sort` — `currency`, `rate` или `date`; `desc` — `true` для убывающего порядка.

```http
GET http://localhost:8080/answer?currencies=USD,EUR&sort=rate&desc=true
```

### Получить курс валюты на дату

```http
GET http://localhost:8080/answer/USD?date=2026-11-08
```

### Запустить сбор актуальных данных

```http
POST http://localhost:8080/api/rates/collect
Content-Type: application/json

{
  "currencies": ["USD", "EUR", "CNY", "GBP", "JPY"]
}
```

Ответ имеет статус `202 Accepted` и содержит `jobId`. Состояние задачи проверяется запросом:

```http
GET http://localhost:8080/api/rates/jobs/{jobId}
```

Статус `COMPLETED` означает успешное обновление. Во время работы приложения консоль H2 доступна по адресу `http://localhost:8080/h2-console`: URL подключения — `jdbc:h2:file:./data/currencydb`, пользователь `sa`, пароль пустой.

## Архитектура и многопоточность

Приложение построено по MVC: контроллеры принимают HTTP-запросы, сервисы реализуют бизнес-логику, репозиторий работает с H2 через JPA.

| Требование | Реализация |
|---|---|
| Простые потоки | демон-поток `collection-dispatcher` создан через `Thread` и выполняет `Runnable`-цикл обработки задач |
| Пул потоков | настроенный `ThreadPoolExecutor` с именованными потоками `rate-parser-*` |
| Producer–Consumer | `LinkedBlockingQueue` принимает задачи сбора и передаёт их диспетчеру |
| Потокобезопасность | `ConcurrentHashMap`, `AtomicReference`, `ReentrantLock` с честной политикой блокировки |
| Планирование | `@Scheduled` обновляет стандартный стек валют; `ScheduledExecutorService` очищает устаревшие задачи |
| Хранение | встроенная H2 и Spring Data JPA |
| Параллельная обработка | выборка, фильтрация и сортировка данных H2 выполняются через `parallelStream()` |
| Межсервисное взаимодействие | Spring WebFlux `WebClient` получает XML от ЦБ РФ |

Запись в JPA выполняется последовательно в транзакции, так как `EntityManager` не предназначен для одновременного доступа из нескольких потоков. Параллельный Stream применяется к уже полученному списку результатов.

## Тестирование и сборка

```powershell
.\mvnw.cmd clean verify
```

Тесты проверяют API выборки и сортировки, асинхронную постановку задачи и разбор XML-ответа ЦБ РФ. Итоговый исполняемый JAR создаётся в `target/`; готовая копия для запуска включена в каталог `release/` итогового архива.
